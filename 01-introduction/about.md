# Bash Scripting - Introduction

## What is Bash?

Bash (Bourne Again Shell) is a Unix shell and command interpreter. It acts as a bridge between the user and the Linux kernel by interpreting commands entered by the user and executing them.

---

## Why was Bash Created?

Managing Linux systems manually becomes difficult when repetitive tasks must be performed frequently.

Examples include:

- Creating backups
- Monitoring disk usage
- Checking system health
- Managing users
- Deploying applications

Instead of typing the same commands repeatedly, Bash allows us to automate them using scripts.

---

## What is a Shell?

A shell is a program that accepts user commands, interprets them, and communicates with the Linux kernel.

Architecture:

User
↓
Bash Shell
↓
Linux Kernel
↓
CPU, Memory, Storage

---

## What is a Bash Script?

A Bash script is a text file containing one or more Linux commands that are executed sequentially by the Bash interpreter.

Example:

date
pwd
whoami

Instead of typing these commands individually, they can be stored in a script and executed together.

---

## Why is Bash Important for DevOps?

Bash scripting is widely used to automate Linux administration tasks, including:

- Server provisioning
- Application deployment
- Backup automation
- Log analysis
- System monitoring
- CI/CD pipelines

Most DevOps tools execute Bash commands behind the scenes.

---

## Key Takeaways

- Bash is a command interpreter.
- Bash connects users with the Linux kernel.
- Bash scripts automate repetitive tasks.
- Automation reduces manual effort and improves consistency.
- Bash is a foundational skill for DevOps engineers.
